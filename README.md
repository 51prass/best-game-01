LUMEN: Keeper of the Last Light — an original lighthouse-defense arcade game. Shadow creatures crawl out of a dark sea toward the last lighthouse; aim its beam with the mouse, hold click to burn them down, collect light shards, and spend them on upgrades between 10 waves. Survive all 10 waves to win, then keep going in endless mode. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, vanilla JavaScript and canvas. Mouse aims the beam, hold click (or Space) to fire, P pauses, R restarts, M mutes.
